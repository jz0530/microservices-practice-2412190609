# 第六周作业系统填写文字

仓库：https://github.com/jz0530/microservices-practice-2412190609

## 1. 服务拆分设计
本项目保留原有单体工程，拆分为用户、商品和订单三个独立微服务。用户服务负责买家资料，商品服务负责发布查询及唯一占用，订单服务通过 HTTP 校验用户和占用商品后保存订单。各服务使用独立数据库与账号，仅保存跨服务 ID，不直接读取其他服务的数据表；设计文档已记录服务边界、端口、数据归属及 Mermaid 架构图。

## 2. 代码拆分
三个服务均具备独立 Maven 工程、配置、Controller、Service 和测试。订单服务使用 RestTemplate 完成真实 HTTP 调用，并配置地址覆盖、连接和读取超时。共 18 项测试通过，验证正常下单、并发占用和依赖失败处理。
建议截图：01-services.png、05-success.png。

## 3. 本地编排
通过根目录 Docker Compose 启动三个 Spring Boot 服务及三个 MySQL 8.4.11 数据库。各服务使用独立数据库账号、网络和命名数据卷，容器通过服务名通信，数据库健康后启动对应应用；三个服务健康接口均返回 200 和 UP。
建议截图：02-compose.png。

## 4. 验证
从仓库根目录执行健康检查和业务验证脚本。正常下单返回 201，商品变为 RESERVED；重复购买返回 409，资源不存在返回 404，停止商品服务后返回 503，各失败场景未新增订单。文档说明了远端占用成功但本地保存失败的窗口，未声称实现跨服务原子事务。
