# 第四周作业系统填写文字

仓库链接：https://github.com/jz0530/microservices-practice-2412190609

## 1. 业务建模
本周沿用校园二手交易与担保履约平台，实现商品发布、商品查询、买家下单并占用商品的核心流程。使用商品与订单两个实体，订单关联商品并保存成交价格快照。Service 检查只有在售商品能够下单，已占用商品拒绝重复购买；当前不包含支付、取消和登录认证。

## 2. 单体应用实现
在原 monolith 中完成商品与订单模型、Service、Controller 和 DTO，实现发布商品、查询列表、商品详情、下单及订单详情五个接口。验证正常创建返回 201，查询返回 200，无效输入返回 400，不存在返回 404，重复购买返回 409。

## 3. 数据库持久化
使用 MySQL 8.4.11 与 Spring Data JPA，建立商品和订单两张表，配置主键、订单商品外键和唯一约束。下单使用事务及行锁。已实际写入商品和订单，并在应用重启后成功查询，证明数据持久化有效；测试数据由测试代码自动准备。

## 4. 测试与验证
在 monolith 目录执行 ./mvnw.cmd test（Windows，Linux 为 ./mvnw test），使用独立 H2 测试数据库，覆盖 Repository 读写与约束、Service 业务规则以及 API 正常和错误响应。14 项测试通过，失败和错误均为 0。
