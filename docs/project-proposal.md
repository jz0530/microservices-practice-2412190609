# 项目选题说明

## 项目名称与目标用户

沿用第 02 周选题：**校园二手交易与担保履约平台**。面向校内学生买家、学生卖家及平台管理员。学生使用同一账号参与买卖，管理员负责商品审核和纠纷处理。

## 优先实现的业务场景

学生卖家发布闲置商品，买家浏览详情并下单，系统记录商品占用和订单状态，避免同一件商品被重复购买。后续逐步增加校内面交、模拟担保付款、确认放款和结算前简单纠纷处理。

## 两个核心模型（仅规划）

| 模型 | 职责 | 初步信息 |
| --- | --- | --- |
| 商品 | 描述一件可交易的校园闲置及其可售状态 | 编号、卖家、标题、描述、价格、状态 |
| 订单 | 记录买卖双方针对一件商品的交易过程 | 编号、商品编号、买家、卖家、成交金额快照、状态、创建时间 |

本学期以单校园、固定价格、一单一件、面交和模拟资金为边界。本周只记录模型规划，不创建业务模型类、不连接数据库。

## 第 03 周实现范围

创建 Java 25、Spring Boot 4.0.8、Maven 工程，Group 与源码／测试包名均为 com.zjgsu.cyy。配置 application.yml、8080 端口、Spring Web MVC 和 Actuator，实现 GET /api/hello 并验证 /actuator/health，使用 @SpringBootTest 的 contextLoads 测试验证应用上下文加载。注册登录、商品与订单 CRUD、Service、Repository、数据库和实际交易能力均不在本周实现范围。
